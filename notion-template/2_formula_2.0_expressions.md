# Notion Formula 2.0 高度数式ロジック集

Notion最新の **Formula 2.0（関数2.0）** 仕様に対応した、コピペですぐに使える実戦数式コード集です。
ShoruiFlowテンプレートの「見積・請求ステータスDB」にそのまま貼り付けて利用できます。

---

## 1. 請求書発行漏れ＆未回収アラート (`請求アラート`)

案件が「受注/着手」または「納品書」の状態で請求書が発行されていない場合、または支払期日を過ぎて未入金の場合に目立つ警告バッジを表示します。

```javascript
/* プロパティ依存: prop("ステータス"), prop("書類種別"), prop("支払期日・納期") */
ifs(
  /* 1. すでに入金完了している場合 */
  prop("ステータス") == "入金完了",
  "✅ 入金確認済",

  /* 2. 請求済だが支払期日を超過している場合 */
  prop("ステータス") == "請求済/入金待ち" and !empty(prop("支払期日・納期")) and now() > prop("支払期日・納期"),
  "🚨 入金期日超過 (" + dateBetween(now(), prop("支払期日・納期"), "days") + "日遅延)",

  /* 3. 納品済みまたは受注中なのに請求ステータスになっていない（請求漏れ） */
  (prop("書類種別") == "納品書" or prop("ステータス") == "受注/着手") and prop("ステータス") != "請求済/入金待ち",
  "⚠️ 請求書未発行！(納品・着手済)",

  /* 4. 見積書が提出されてから有効期限が切れた場合 */
  prop("書類種別") == "見積書" and !empty(prop("支払期日・納期")) and now() > prop("支払期日・納期"),
  "⌛ 見積有効期限切れ",

  /* 5. 順調に請求中・期日内 */
  prop("ステータス") == "請求済/入金待ち",
  "⏳ 入金待ち (期日内)",

  /* デフォルト */
  "⚪ 通常進行"
)
```

## 2. 納期・期日カウントダウン表示 (`納期カウントダウン`)

「支払期日・納期」プロパティを基準に、締切までの残り日数をスマートな日本語ラベルで視覚化します。

```javascript
/* プロパティ依存: prop("支払期日・納期"), prop("ステータス") */
ifs(
  empty(prop("支払期日・納期")),
  "📅 期日未設定",

  prop("ステータス") == "入金完了" or prop("ステータス") == "失注",
  "— 完了",

  dateBetween(prop("支払期日・納期"), now(), "days") < 0,
  "🔴 " + abs(dateBetween(prop("支払期日・納期"), now(), "days")) + "日 超過！",

  dateBetween(prop("支払期日・納期"), now(), "days") == 0,
  "🔥 本日締切！",

  dateBetween(prop("支払期日・納期"), now(), "days") <= 3,
  "⚡ あと " + dateBetween(prop("支払期日・納期"), now(), "days") + " 日",

  "残り " + dateBetween(prop("支払期日・納期"), now(), "days") + " 日"
)
```

## 3. 案件別 粗利益＆利益率 自動計算 (`粗利益 / 利益率`)

売上（税込合計）からリレーション先の外注費・経費のロールアップ合計を差し引き、粗利額と利益率を算出します。

### 3.1 粗利益額（円）
```javascript
/* プロパティ: prop("税込合計金額"), prop("外注費合計") */
let(
  revenue, if(empty(prop("税込合計金額")), 0, prop("税込合計金額")),
  cost, if(empty(prop("外注費合計")), 0, prop("外注費合計")),
  revenue - cost
)
```

### 3.2 利益率（%表示）
```javascript
/* 粗利益率を算出し、バーグラフ風に装飾 */
let(
  revenue, if(empty(prop("税込合計金額")), 0, prop("税込合計金額")),
  cost, if(empty(prop("外注費合計")), 0, prop("外注費合計")),
  profit, revenue - cost,
  rate, if(revenue == 0, 0, round((profit / revenue) * 100)),
  
  ifs(
    revenue == 0, "0%",
    rate >= 70, "🟢 " + rate + "% (高収益)",
    rate >= 40, "🟡 " + rate + "% (標準)",
    rate > 0,   "🟠 " + rate + "% (薄利注意)",
    "🔴 " + rate + "% (赤字)"
  )
)
```

## 4. インボイス適格請求書 税率内訳シミュレータ (`内訳検証`)

標準税率10%対象額と軽減税率8%対象額をNotion内で即時チェックするための数式です。

```javascript
/* プロパティ: prop("税抜小計"), prop("消費税額") */
let(
  subtotal, prop("税抜小計"),
  tax, prop("消費税額"),
  expectedTax10, round(subtotal * 0.1),
  
  if(
    empty(subtotal) or empty(tax),
    "未計算",
    if(
      tax == expectedTax10,
      "✔ 10%標準税率 一致 (¥" + tax.format() + ")",
      "ℹ 軽減税率(8%)混在 または 端数調整済 (¥" + tax.format() + ")"
    )
  )
)
```
